一个聚合市场：Add 本仓库，即可安装下列全部插件。

## 安装

```
ZCode → Plugin Marketplace → Add → Add Plugin Marketplace
→ 粘贴 https://github.com/forrestneo/zcode-market
→ Personal → forrestneo-zcode-market → 选择插件 → Install
```
